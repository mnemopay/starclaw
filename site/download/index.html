Get StarClaw

There is no installer. No desktop app, no .exe or .dmg, no app-store listing and no hosted service exist yet. What exists today is a command-line package on npm and the source code on GitHub.

1. From npm (the published alpha)

npm install starclaw@next

This installs 2.0.0-alpha.3, which is what the next tag on npm points to right now. Always include @next. Plain npm install starclaw installs the old 1.0.0, which is deprecated and broken.

Package page: npmjs.com/package/starclaw.

2. From source (slightly newer)

The main branch on GitHub is at 2.0.0-alpha.5, which is not published to npm. It adds the Slack and Discord channels and the governed browser tools.

git clone https://github.com/mnemopay/starclaw && cd starclaw && npm install && npm run build
node dist/cli.js doctor

Source: github.com/mnemopay/starclaw (Apache-2.0).

What you need

  • Node.js 25.9.0 or newer. Older versions are refused on purpose.
  • A model API key. The bundled backend is Groq; others are configurable in the policy.
  • Docker, if you want the container sandbox layer. Optional but recommended. Without it only the weaker Node permission layer is used.
  • Tested on Windows 11 x64 only. Linux and macOS are untested.
