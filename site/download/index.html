Developer alpha (2.0.0-alpha.15). Read the security model first: StarClaw limits what a steered model can do, it does not prevent prompt injection.

1. Windows: the installer

Download StarClaw-Setup-2.0.0-alpha.15.exe from GitHub Releases. It installs for your user only (no admin prompt), bundles Node.js 25.9.0, and adds a Start-menu shortcut. Each installer is installed, run and uninstalled on a clean Windows machine by CI before it is published. It is not code-signed yet, so Windows SmartScreen will warn: choose More info, then Run anyway, after checking the file against SHA256SUMS.txt on the release page.

2. macOS and Linux: one command

MACOS / LINUX

No sudo, nothing outside your home directory. It uses your Node.js if it is 25.9 or newer, otherwise it downloads the official Node.js 25.9.0 and checks it against nodejs.org's published checksums before using it. Then run starclaw-app. Read the script before you run it. CI runs it on clean Ubuntu and macOS machines for every release.

3. From npm

ANY OS WITH NODE.JS 25.9+

This installs 2.0.0-alpha.15. Start the console with starclaw app. Package page: npmjs.com/package/starclaw.

4. From source

git clone https://github.com/mnemopay/starclaw && cd starclaw && npm install && npm run build
node dist/cli.js doctor

Source: github.com/mnemopay/starclaw (Apache-2.0).

What you need

  • An AI model. On first run a setup page finds Ollama or LM Studio running on your computer (free and private) or takes a Groq, Anthropic, OpenAI or OpenRouter key, and tests the model before saving anything.
  • Node.js 25.9.0 or newer for the npm and source routes. The installers bring their own.
  • Docker if you want the container sandbox layer. Optional but recommended; without it only the weaker Node permission layer is used.
  • The console opens in your browser on 127.0.0.1 only. Telegram, Slack, Discord, WhatsApp, Signal and email are optional channels you configure in the policy.
