StarClaw, OpenClaw
and Hermes Agent.

Three open-source agents that act for you. They differ most in what stops an agent that has been steered by something it read.

The difference in one sentence

StarClaw assumes the model will sometimes be steered by something it read, and puts its effort into what happens next: what the agent may do without you, what it must ask, and a signed record of every decision that you can check yourself. It does not prevent prompt injection, and neither does any agent we know of.

Where the others are ahead

  • Maturity and community. OpenClaw and Hermes Agent have far larger user bases (Hermes Agent's repository shows about 264k GitHub stars [1]). StarClaw is a developer alpha.
  • Apps. OpenClaw has desktop and mobile apps and voice [2]. StarClaw's console runs in your browser.
  • Memory. Hermes Agent models the user over time and searches past sessions with summaries [1]. StarClaw keeps signed memory and conversation search, but deliberately does not carry earlier untrusted content into a clean session.
  • Self-improving skills. Hermes Agent writes and revises its own skills [1]. StarClaw's agent-written skills need your approval each time.
