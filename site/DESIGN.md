# StarClaw — The Autonomous Observatory

Audience: developers, independent founders and small teams who want an agent that does useful work while preserving ownership.
Intent: a memorable product brand, with the precision of scientific instruments and the scale of an editorial cover.

Palette: near-black green #090d0b as the main canvas; ivory #f1f0e8 for type and alternating editorial surfaces; electric chartreuse #d6ff71 for action, active signals and the central sculpture; grey-green #9ca79d for secondary text. No purple/blue gradient branding.
Typography: locally hosted Space Grotesk for display/body; IBM Plex Mono for labels, commands, instrumentation. Hero 96–112px desktop, 60px mobile; section headings 56–72px; body 16–18px. Tight display tracking, generous body leading.
Grid: 1280px max width with 64px desktop gutters; 24px mobile gutters. Asymmetrical hero; 12-column editorial sections. Spacing in multiples of 8. Full-bleed changes in surface rather than repeated card grids.
Identity: an original six-point star/claw mark. A rotating particle knot is the hero sculpture, paired with precise orbital annotations. This is original procedural canvas art, not a simulated product screenshot.
Section direction:
1. Hero: oversized, restrained statement at left; luminous sculptural star knot at right. Quiet command-copy interaction and two clear actions.
2. Capability lab: light surface; three selectable use cases and an explicitly illustrative agent activity panel. Each selection changes the scenario and result, with replayable progress.
3. Governance: dark editorial layout, large numbered stages, precise boundaries and a small signed-receipt motif. Security explanation supports the product rather than consuming the hero.
4. Ecosystem: typographic constellation of supported channels and providers. No invented customers, metrics or testimonials.
5. Closing: monumental CTA, compact installation command and honest alpha information.
6. Docs/security/download: the same brand shell, strong page titles, readable article widths, sticky local contents where appropriate, useful command panels.
Motion: slow continuous 3D movement, small staggered reveals and purposeful state transitions. Stop off-screen and respect reduced motion. Never delay access to content.
Interactions: accessible mobile navigation, copy buttons with feedback and fallback, keyboard-operated capability tabs, a walkthrough dialog with focus restoration, functional internal links. No pretend signup forms or backend actions.
Avoid: generic bento grids, fake statistics, invented security guarantees, decorative dashboards masquerading as actual product screenshots, excessive warnings as marketing copy, custom cursors and scroll hijacking.
