Who approved: every human-approval step in this run was decided by Claude acting for the maintainer, after reading each request. Not by an end user, and not by the maintainer in person.

What ran

  • Engine: StarClaw 2.0.0-alpha.10, process-permission sandbox (Docker was off).
  • Model: Claude Sonnet 5.5 via OpenRouter. One attempt. Model spend: about $0.10.
  • Repository: mnemopay/mnemopay-sdk @ 5366c69 (v1.17.0).
  • Bug: verifyBundle() accepted a tampered audit bundle whose last event was duplicated, when the event count was odd. The project's own docs admitted it.
  • Task given: fix it with the smallest safe change, keep valid bundles verifying, don't change how the Merkle root is computed, and add a test.

Result

  • The agent changed src/governance/audit-chain.ts (a new sequence_mismatch check after the unchanged root check) and added a test to tests/audit-chain.test.ts.
  • The new test fails on the original code (1 failed | 13 passed (14)) and passes with the patch (14 passed (14)).
  • Full SDK suite with the patch: 1454 passed, 3 skipped, 0 failed.
  • The job itself ended on a denial: its last step wanted to run the tests inside a Docker container, Docker was off, so that step was denied. Both files had already been written. The tests above were run afterwards, outside StarClaw.

Approvals

4 approved by Claude acting for the maintainer (2 sandbox runs, 2 file writes), 1 denied (container test run; Docker was off). File reads inside the workspace were allowed by policy without asking. All 14 decisions are in the signed log below.
